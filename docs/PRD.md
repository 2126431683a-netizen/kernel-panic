## 1. 背景与问题

割草生存（Survivors-like）是近年验证过的独立游戏品类：操作极简（移动+自动攻击），
但通过成长构建产生强复玩性。市面同类普遍存在的问题：

1. **题材同质化**——哥特/魔幻皮占绝对多数，缺少本土文化语境的作品
2. **成长反馈慢**——前期 5~10 分钟感受不到构建成型
3. **美术风格单一**——像素复古风泛滥，二次元动漫风的同类作品稀少

本项目以「失控的生产环境 + 系统管理员杀进程」为叙事外壳，把**程序员运维文化**
（kill -9、PID、内存扩容、补丁）转译成游戏机制语言，并以**北京城市动漫美术**
（故宫/胡同/国贸天际线）建立差异化辨识度。

## 2. 目标用户

| 人群 | 需求 | 对应设计 |
|---|---|---|
| 程序员/互联网从业者 | 会心一笑的梗与身份代入 | 杀进程叙事、kill -9 击杀日志、运维术语升级系统 |
| 割草品类玩家 | 快节奏成长爽感 | 30 秒一波、分钟级构建成型、精英 Boss 节奏点 |
| 二次元玩家 | 动漫立绘与角色演出 | AI 生成动漫角色全套动画、Q 版吉祥物、动漫 UI |
| 游戏开发学习者 | 可读的开源项目 | 全代码注释 + PRD/GDD/源码讲解三文档 + 可调参配置 |

## 3. 产品目标

- **体验目标**：单局 5~15 分钟，局内成长构建可见、死亡有总结欲（再来一局）
- **技术目标**：Godot 4 单项目可维护；全部美术资产 AI 生成管线化（可换皮重出）
- **学习目标**：作为「AI 美术管线 + Godot 程序化动画 + 割草框架」的完整教学样例

## 4. 需求清单

### P0（已实现 · 核心 loop）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| P0-1 | 虚拟摇杆式 8 向移动（WASD/方向键） | 移动跟手，arena 边界钳制 |
| P0-2 | 自动锁定最近敌人开火 | 无目标不空射；火力间隔可升级 |
| P0-3 | 四类敌系（杂兵/疾行/重甲/精英）| 行为差异可感知：速度/血量/伤害/跳跃高度 |
| P0-4 | 刷怪导演：时间驱动密度+血量成长 | 8 分钟后压力显著升级，不出现真空期 |
| P0-5 | 击杀掉经验 → 升级三选一补丁 | 升级暂停世界，选择不可跳过 |
| P0-6 | 死亡结算 + 一键重开 | R 重启 < 1 秒 |
| P0-7 | 主菜单 / 操作说明 / 暂停 / 结算全 UI 流 | 键盘+鼠标双通道可完成全部流程 |

### P1（已实现 · 体验增强）

| 编号 | 需求 | 说明 |
|---|---|---|
| P1-1 | 动漫美术全套 | 11 张 AI 生成资产：角色/敌人/子弹/经验/地图/标题/结算/吉祥物 |
| P1-2 | 角色移动动效 | 颠步+挤压拉伸+倾斜+朝向+扬尘；敌人蹦跳+落地压扁 |
| P1-3 | 北京地图 | 故宫/胡同/国贸天际线动漫鸟瞰 + 全息网格 |
| P1-4 | 音效合成 | 运行时生成 8-bit 音效（射击/命中/击杀/升级/受伤/结算），零音频文件 |
| P1-5 | 击杀日志终端彩蛋 | `> kill -9 PID xxxx [GLITCH] — terminated` |

### P2（规划中 · 见路线图）

| 编号 | 需求 | 说明 |
|---|---|---|
| P2-1 | 逐帧行走动画 | sprite-gen 图集接入 AnimatedSprite2D（管线已就绪） |
| P2-2 | 武器分支 | 散射/激光/导弹等第二武器系 |
| P2-3 | Boss 战 | 每 5 分钟精英升级为带技能 Boss（弹幕/冲锋） |
| P2-4 | 元进度 | 局外解锁：初始补丁、角色皮肤（recolor 管线已具备） |
| P2-5 | 本地最高分 | 存档持久化 |

### 非目标（明确不做）

- 多人联机、移动端触控适配（当前阶段）
- 剧情叙事系统（梗文化靠日志与文案承载）
- 3D 渲染、物理引擎模拟（碰撞用距离判定，见 CODE_GUIDE 设计决策）

## 5. 成功指标

| 维度 | 指标 | 目标 |
|---|---|---|
| 爽感 | 首局平均存活 | ≥ 4 分钟 |
| 成长感 | 单局平均升级次数 | ≥ 8 级 |
| 复玩 | 首局死亡后重开率 | ≥ 60% |
| 学习 | 第三方按 CODE_GUIDE 新增一种敌人 | ≤ 30 分钟 |

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| AI 连帧一致性差 → 行走动画闪烁 | sprite-gen 组件行管线锁定身份；QA 不过则程序化动画兜底（已实现） |
| 图像 API 不稳定 | 资产全部落盘；管线脚本支持过滤重跑单张 |
| 后期敌人堆叠性能 | 上限 220 + O(n) 距离判定 + 分帧群体分离（见 CODE_GUIDE §性能） |
| 单调感 | 30s 波次横幅 / 75s 精英 / 升级三选一的节奏锚点 |

## 7. 路线图

- **v2.1（当前）**：动漫化 + 北京地图 + 全套 UI + 程序化动效 + sprite-gen 管线接入
- **v2.2**：逐帧行走动画上线、Boss 战、武器分支
- **v3.0**：元进度 + 皮肤系统（palette-swap）+ 成就
